# Mobile Usage prototype verdict

Question: How should the Usage settings page reorganize its information on a narrow mobile screen?

Verdict: Variant A, “Overview first”. The production page should lead with a full-width token total, keep requests/output/cache as compact secondary metrics, retain a full-width trend chart, and replace the five-column mobile table with provider cards that show token share and compact secondary metrics. Desktop keeps the existing dense table.

Variants B and C remain here only as primary-source evidence for the design decision.
